# CreativeFN WS / Creative Logic Mobile

An offline Android companion for manually constructing Fortnite Creative 1.0 device logic. The original Phase 3.2 graph editor, Room Library and deterministic TEST SCENE remain unchanged. All Fortnite game behavior is a scoped experiment, not a 1:1 emulator.

**Certified predecessor:** Android run [38458909239](https://github.com/MavyyBlue/CreativeFN-WS/actions/runs/38458909239) passed at `363dde7c`; the owner confirmed the Graph, device inspector and compact panel visible above Fortnite. The Cover Flow workspace redesign below is a separate CI-pending candidate. The **Blueprints** control accesses saved mechanics from any application screen. Save the graph, open **Guide** for a device bill of materials, exact saved option values, bindings and checklist; choose **Overlay** to request Draw Over Other Apps and start a small passive FN reference bubble with Steps, Links and zoomable Graph (new candidate; previous release had a separate Devices tab). A persistent notification has Stop Overlay. `.c1logic` import/export uses the local Android document picker and preserves the original graph document JSON format.

How to use: Create → Devices and Bindings → Simulate → Save → Blueprints → Guide → Overlay → approve permission → return to Fortnite → tap FN bubble. Collapse and reopen without leaving Fortnite. Settings and checkbox progress refer to the frozen saved graph; save and launch the overlay again for newly edited changes. The overlay is subject to OEM and Fortnite restrictions that require phone testing. It does not inspect or control the game.

Build and CI: JDK 21, Android SDK API 37 and Gradle 9.6 wrapper. Use `./gradlew check lintDebug assembleDebug assembleDebugAndroidTest`. Android emulator jobs and physical phone tests are separate acceptance gates. See [current state](docs/CURRENT_STATE.md), [roadmap](ROADMAP.md), [overlay boundaries](OVERLAY.md), [fidelity ledger](FORTNITE_FIDELITY.md), and [mobile delivery](docs/MOBILE_DELIVERY.md).

No account, internet connection, cloud service, file-storage permission, AccessibilityService or background simulation is used. Do not regenerate existing signing keys. The existing Room schema 1 is not migrated; the update should install over a matching signed APK, but check actual certificate identity before replacing the installed app.

## Compact blueprint overlay follow-up (2026-10-13)

Owner phone testing confirmed a working passive overlay above Fortnite but found the Graph tab blank and the panel too large in landscape. The new candidate defaults to approximately one-quarter of a landscape screen (52% × 52%), adds an in-window **Size** control with width/height sliders and compact reset, and lets **Tabs − / Tabs +** hide the navigation row without leaving the current instructions or graph. Position and size are remembered per orientation; Graph now provides touch pan/pinch-to-zoom and **Fit graph** with an Android draw regression test. All gameplay/editor/simulator/storage code is unchanged. This compact sizing/graph fix subsequently passed CI run `38441055829` and was confirmed by the owner in Fortnite. The newer connection explorer/gestures still require independent CI and phone testing.

## Three-view overlay follow-up (new source candidate; not yet CI certified)

The landscape Graph and resizing were subsequently observed working on the owner's Android phone above Fortnite. The next update simplifies the overlay tabs to **Steps / Links / Graph**. Tap a graph node to inspect its saved options and exact direct bindings. Hold a node to temporarily focus its direct neighbors; unrelated nodes/wires dim but remain interactive, and double-tapping empty space exits focus. Links becomes a collapsed device directory with incoming/outgoing port labels and user-named one-hop connection folders. Device folders do **not** change the actual graph or simulate anything; they persist through the existing Room document and optional format-2 `.c1logic` metadata field. The foreground notification, manual overlay permission, compact sizing, navigation toggle and simulator remain. CI and repeat phone acceptance are pending for the new gestures and folder keyboard flow.

## Cover Flow navigator (2026-10-13 — awaiting new CI and phone acceptance)

The latest source candidate replaces the in-panel Steps/Links/Graph tab row with a compact **floating Cover Flow-inspired navigation carousel beneath the blueprint panel**. Tap or swipe its angled cards to choose a workspace. The selected tab occupies the complete dark panel; graph nodes/lines now fill the available area, with saved device configuration shown in a compact overlaid inspector after tapping a node. Drag by the `⋮⋮` grip, use the `⋯` control to change size, hide/show carousel, collapse, or Stop, or stop from the notification. The carousel stays in its own tightly bounded transparent overlay window and follows the main panel. Existing folder organization, connection focus, saved guides and deterministic simulator remain. The source package has not been Android- or Fortnite-tested yet; upload via the established mobile importer and treat GitHub CI plus phone tests as the gate.

### Inline Graph card (Android CI pending)

The current, phone-observed Cover Flow graph is updated to let a builder **tap a node to expand it in place**, exposing saved options and exact linked Event → Function routes. Tap the same node again to collapse; long-press Connection Focus and double-tap empty graph space remain. A tall node scrolls details within the card, while the graph itself can still pan, pinch or Fit. The separate bottom inspector has been removed, keeping the full-height graph. The layout change is read-only and does not move saved graph nodes. The new candidate requires Android CI, instrumentation, and Fortnite phone verification.
